# ramonyml.github.io

Portfólio pessoal — React 19, TypeScript, Vite e Tailwind CSS 4.

🔗 [ramonyml.github.io](https://ramonyml.github.io)

## Stack

- React 19 + TypeScript
- Vite + `@tailwindcss/vite`
- `@fontsource/ubuntu` (fonte self-hosted)
- Deploy automático via GitHub Actions → GitHub Pages a cada push em `main`

## Rodando localmente

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
